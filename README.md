## Selam, ben Bilal.

Makine mühendisliği geçmişim var; Android uygulamaları, oyunlar ve web araçları geliştiriyorum. Küçük bir fikri çalışan bir ürüne dönüştürmeyi seviyorum. Google Play'deki uygulamalarımı **Vitrincim** adıyla yayımlıyor, kullandığım araçların bir bölümünü burada açık kaynak olarak paylaşıyorum.

Son dönemde yapay zekâ araçlarıyla oyun geliştirme sürecimi de belgeliyorum: hangi tekniği kullandım, nerede tıkandım, neyi değiştirdim. [Yöntem defteri](https://github.com/bilalfarukozdemir/yapay-zekayla-oyun) · [YouTube: @bilaldevlog](https://www.youtube.com/@bilaldevlog)
